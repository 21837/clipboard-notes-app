# 功能笔记应用 - Electron 桌面应用

## 📋 项目说明

这是一个基于 Electron 开发的桌面应用程序，具备以下功能：
- 实时监测系统剪切板
- 历史记录管理
- 笔记编辑与保存
- 系统托盘驻留
- 全局快捷键

## 🚀 快速开始

### 1. 安装依赖

打开终端，进入项目目录，运行：

```bash
cd C:\Users\21837\Desktop\.trae\clipboard-notes-app
npm install
```

### 2. 运行开发版本

```bash
npm run dev
```

应用将启动并显示主窗口。

### 3. 打包生成 exe 文件

```bash
npm run build:win
```

打包完成后，exe 文件位于 `dist/` 目录。

## 📁 项目结构

```
clipboard-notes-app/
├── main.js              # Electron 主进程（窗口管理、托盘、剪切板监测）
├── preload.js           # 预加载脚本（安全桥接）
├── src/
│   ├── index.html       # 主页面
│   └── renderer.js      # 渲染进程逻辑
├── assets/              # 图标资源
├── package.json         # 项目配置
└── README.md            # 说明文档
```

## 🎯 核心功能

### 剪切板监测
- 后台每 500ms 检测一次剪切板变化
- 自动捕获并保存复制内容
- 去重处理，相同内容移到最前面

### 数据持久化
- 使用 electron-store 保存数据
- 历史记录和笔记内容自动保存
- 窗口位置和大小记忆

### 系统托盘
- 右键菜单：显示/隐藏窗口、开机启动、退出
- 双击托盘图标显示窗口
- 后台运行，不占用任务栏

### 全局快捷键
- `Ctrl+Shift+H`：显示/隐藏主窗口
