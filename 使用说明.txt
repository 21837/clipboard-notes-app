# 功能笔记 — Electron 桌面应用

## 📋 项目说明

基于 Electron 的桌面笔记工具，核心是「**剪切板监测 + Dify RAG 知识库检索**」。

- 实时监测系统剪切板（文本 + 截图）
- 双栏管理：左「未保存剪切板」/ 右「已保存笔记」
- 笔记保存、导出
- 系统托盘驻留 + 全局快捷键
- **接入 Dify 知识库**：复制的内容自动入库（切分 + 向量化），底部输入框用自然语言检索

## 🚀 快速开始

### 1. 安装依赖

在项目目录（本文件所在目录）运行：

```bash
npm install
```

### 2. 运行开发版本

```bash
npm run dev
```

### 3. 打包生成 exe

```bash
npm run build:win
```

产物位于 `dist/` 目录（NSIS 安装包 + `win-unpacked` 免安装版）。

### 4. 配置 Dify（使用 RAG 检索前必做）

1. 复制 `dify-config.example.json` 为 `dify-config.json`
2. 填入两个值：
   - `datasetId`：Dify 控制台 → 知识 → 点开知识库 → 看地址栏 `/datasets/{id}` 中间那段
   - `apiKey`：Dify 控制台 → 知识 → API 访问 → 创建「**数据集**」密钥（`dataset-` 开头）
3. 也可以直接启动应用：**配置缺失时会自动弹出配置窗**；之后可右键托盘图标 →「配置 Dify 知识库...」随时修改

> ⚠️ `dify-config.json` 已写进 `.gitignore`，**不会被提交**（里面是密钥）。
> `baseUrl` 默认 `http://localhost/v1`（本地 Dify），云端部署请改成你的地址。

## 📁 项目结构

```

├── main.js                    # Electron 主进程（窗口 / 托盘 / 剪切板监测 / Dify IPC）

│   └── config.js              # 配置窗口逻辑

├── generate-icon.js           # 图标生成脚本

```

## 🎯 核心功能

### 剪切板监测
- 后台每 500ms 检测一次剪切板变化
- 自动捕获文本与截图（截图保存到系统「图片/功能笔记截图」）
- **按内容指纹（MD5）去重**，同一内容不会重复入历史

### Dify RAG 检索
- 复制的内容自动调用 Dify 知识库 API 入库（**切分与向量化由 Dify 完成**）
- 底部检索栏：输入问题 → 混合检索 + Rerank → 展示命中的分块、得分与来源

### 数据持久化
- 使用 electron-store，数据存放在系统 **userData** 目录（不写入程序目录，兼容打包后的只读 asar）
- 记忆窗口位置与大小
- 存储文件损坏时**自动备份并重建**，不会启动即崩

### 系统托盘
- 右键菜单：显示窗口 / **配置 Dify 知识库...** / 开机启动 / 退出
- 双击托盘图标显示窗口
- 后台运行，不占用任务栏

### 全局快捷键
- `Ctrl+Shift+H`：显示/隐藏主窗口

## ⚠️ 图标说明

`assets/icon.png` 为 256×256 PNG，electron-builder 打包时会据此自动生成 Windows 的 `.ico`。
需要重新生成时运行：

```bash
node generate-icon.js
```

（依赖 `canvas`，已列在 devDependencies。）
