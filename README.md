# 功能笔记应用

一个独立的桌面应用程序，用于监测剪切板内容并管理笔记。

## 功能特性

- ✅ 实时监测系统剪切板，自动捕获复制内容
- ✅ 历史记录列表，最新内容显示在最上方
- ✅ 双栏布局：左侧历史列表，右侧笔记编辑区
- ✅ 点击历史项，内容自动填充到编辑区
- ✅ 文本格式化：加粗、斜体、列表
- ✅ 数据持久化：笔记自动保存到本地
- ✅ 系统托盘驻留：后台运行，不占用任务栏
- ✅ 全局快捷键：`Ctrl+Shift+H` 快速呼出/隐藏窗口
- ✅ 开机自启：可选功能

## 技术栈

- Electron 28.x - 桌面应用框架
- electron-store - 本地数据存储

## 安装依赖

```bash
npm install
```

## 运行开发版本

```bash
npm run dev
```

## 打包生成 exe 文件

```bash
npm run build:win
```

打包完成后，可执行文件位于 `dist/` 目录。

## 使用说明

1. **启动应用**：双击 `功能笔记.exe` 启动应用
2. **复制内容**：在其他应用中复制文本，自动出现在历史列表
3. **选择内容**：点击历史项，内容填充到右侧编辑区
4. **编辑笔记**：在编辑区修改内容，自动保存
5. **隐藏窗口**：点击关闭按钮或按 `Ctrl+Shift+H` 隐藏
6. **系统托盘**：隐藏后，应用在托盘区运行

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+H` | 显示/隐藏主窗口（全局） |
| `Ctrl+B` | 加粗选中文本 |
| `Ctrl+I` | 斜体选中文本 |
| `Ctrl+L` | 将选中文本转换为列表 |
| `Ctrl+S` | 手动保存笔记 |

## 系统托盘功能

右键点击托盘图标：
- 显示窗口
- 隐藏窗口
- 开机启动（勾选启用）
- 退出

## 注意事项

1. 应用需要系统剪切板访问权限
2. 数据存储在用户数据目录
3. 关闭主窗口会最小化到托盘，而不是退出应用
4. 如需完全退出，右键托盘图标选择"退出"

## 自定义图标

如需更换图标，请将图标文件放置在 `assets/icon.ico`，然后重新打包。

## 故障排除

### 剪切板监测不工作
- 确保应用有系统权限
- 重启应用尝试

### 无法打包
- 确保已安装 Node.js 14+
- 运行 `npm install` 重新安装依赖
- 检查网络连接

### 托盘图标不显示
- 系统可能不支持 .ico 格式
- 可以使用 PNG 格式：`nativeImage.createFromPath()`
