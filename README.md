# 功能笔记 (Clipboard Notes)

基于 **Electron** 的桌面笔记工具，核心亮点是：**剪切板监测 + Dify 知识库 RAG 检索**。

复制任何文字，它会自动进入 Dify 知识库（切分 + 向量化）；之后在底部输入框用自然语言提问，就能把「你复制过的一切」检索回来。

## ✨ 功能

### 剪切板监测
- 实时监测系统剪切板（每 500ms），自动捕获**文本与截图**
- 截图保存到系统「图片/功能笔记截图」
- **按内容指纹（MD5）去重**，同一内容不会重复进历史

### 🔍 Dify 知识库检索（RAG，核心功能）
- 捕获的内容自动调用 **Dify 知识库 API** 入库（**切分与向量化由 Dify 完成**）
- 底部检索栏：输入问题 → **混合检索 + Rerank + 阈值** → 展示命中分块、**得分**与来源
- 支持用环境变量 `DIFY_BASE_URL` / `DIFY_DATASET_ID` / `DIFY_API_KEY` 覆盖配置

### 笔记管理
- 双栏布局：左「未保存剪切板」/ 右「已保存笔记」
- 点击历史项填充、保存、导出为 `.txt`、删除
- 系统托盘驻留（后台运行，不占任务栏）+ 全局快捷键 `Ctrl+Shift+H`
- 开机自启（可选）
- 记忆窗口位置与大小

## 🧱 技术栈

| 层 | 技术 |
|---|---|
| 桌面框架 | Electron 28 |
| 界面 | 原生 HTML / CSS / JavaScript（无前端框架） |

## 🚀 快速开始

```bash
npm install
npm run dev         # 开发运行
npm run build:win   # 打包 exe（产物在 dist/）
```

也可以直接双击 `启动应用.vbs`（免命令行启动）。

### 配置 Dify（用 RAG 检索前必做）

1. 复制模板：`dify-config.example.json` → `dify-config.json`
2. 填入两个值：
   - `datasetId`：Dify 控制台 → 知识 → 点开知识库 → 看地址栏 `/datasets/{id}`
   - `apiKey`：Dify 控制台 → 知识 → API 访问 → 创建「**数据集**」密钥（`dataset-` 开头）
3. **或者**直接启动应用：配置不完整时会**自动弹出配置窗**；之后可右键托盘图标 →「配置 Dify 知识库...」随时修改

> ⚠️ `dify-config.json` 已被 `.gitignore` 排除（内含密钥，不会被提交）。
> `baseUrl` 默认 `http://localhost/v1`（本地 Dify），云端部署请改。

## 🛠 工程要点（开发 → 打包踩过的坑）

这个项目从"开发能跑"到"打包能用"踩了不少坑，都已修复，记在此处备查：

- **asar 只读**：打包后 `__dirname` 位于只读的 `app.asar`（对操作系统而言是"文件"不是目录），任何**写操作**必须走 `app.getPath('userData')`，否则启动即崩（`ENOTDIR`）。
- **轮询 + 无去重 = 刷屏**：剪切板监听若不做去重，剪切板里的图片会被每 500ms 重复入库一次。
- **去重要用内容指纹**：不能拿"带时间戳的文件路径"比对，否则永远不相等、永远去不了重。
- **本地图片预览**：`file://` URL 需用 `pathToFileURL()` 正确编码（Windows 路径含反斜杠/中文），且 CSP 需放行 `img-src file: data:`。
- **配置容错**：存储文件损坏（如被写入 BOM）时自动备份并重建，而不是启动即崩。
